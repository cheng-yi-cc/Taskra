# 课迹 Taskra

面向大学生的个人作业本：记录课程作业 → 查看未完成作业 → 完成后按课程保存 → 期末重新练习。

- 本地优先，核心功能全部离线可用；无账号、无服务器、无广告、无埋点。
- 技术栈：Kotlin + Jetpack Compose + Material 3（自定义暖色主题）+ Room + DataStore + 协程/Flow。
- 单 `app` 模块，按功能组织界面，按职责分离数据、时间、图片、备份服务。

## 构建与安装（无需打开 Android Studio）

前置：JDK 17，Android SDK（含 platform-tools、platforms/android-35、build-tools/35.0.0）。
`local.properties` 已指向本机 SDK；换机器请修改 `sdk.dir`。

```bat
cd "D:\My Project\Taskra"
.\gradlew.bat :app:assembleDebug --no-daemon
.\gradlew.bat :app:testDebugUnitTest --no-daemon
```

产物：`app\build\outputs\apk\debug\app-debug.apk`（**调试版**，包名 `com.taskra.debug`）。

建议先安装到不含用户数据的模拟器，使用 `adb devices -l` 确认序列号：

```bat
%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe -s <模拟器序列号> install -r app\build\outputs\apk\debug\app-debug.apk
```

**已有用户数据的手机**：覆盖安装本身不保证数据库安全。更新前须核对包名、签名及数据库版本和迁移路径，完整备份并校验数据库（包括 WAL）、设置和图片、录音；先在隔离模拟器验证升级，再覆盖安装，安装前后及首次启动后核对原有数据。禁止卸载、清除数据、使用更旧的数据库版本或 destructive migration；备份无法验证时不要安装。日常可在设置中使用“导出完整备份”保存标准备份包。

发布版：`release` 构建类型已接正式签名（未启用混淆收缩），包名 `com.taskra`。
签名信息从 `keystore.properties`（本地）或 `TASKRA_KEYSTORE_*` 环境变量（CI）读取；
缺省时 release 包为未签名构建，CI 发版时必须提供密钥。请勿将调试包当作发布包分发。

## 发版与官网（Release + taskra.chengyi.me）

- 打 tag 自动构建：推送 `v*` 标签（如 `v1.0.1`）后，`.github/workflows/release.yml`
  自动用正式签名构建 `:app:assembleRelease`，发布到 GitHub Releases（APK + SHA-256），
  并把官网（含当版 APK 与 `version.json`）同步部署到 Cloudflare Pages。
- 本地签名配置：复制 `keystore.properties.example` 为 `keystore.properties` 后填写
 （该文件已进 `.gitignore`，不会提交）；CI 走同名环境变量
  `TASKRA_KEYSTORE_FILE / TASKRA_KEYSTORE_PASSWORD / TASKRA_KEY_ALIAS / TASKRA_KEY_PASSWORD`，
  密钥内容存 GitHub Secrets（`ANDROID_KEYSTORE_BASE64` 等），仓库里只有示例文件。
- 官网源码在 `site/`（纯静态：`index.html` + `styles.css` + `app.js` + `version.json`），
  暖色极简风格；页面启动时读 `version.json` 自动指向最新安装包，仅提供 Android 版。

## 关键设计选择记录
- 作业状态只有 `TODO/DONE`；草稿、逾期（派生）、复习中、回收站（`deletedAt`）都不进状态字段。
- 完成只改状态不删内容；归档=原记录；复习数据独立保存，不碰原作业字段。
- 仅日期截止=当天结束前，边界为次日 00:00（截止时区）；`DATETIME` 按时刻；设备时区变化不改已存期限（存 `deadlineZoneId`）。
- 图片原图存 `filesDir/images/<id>.jpg`（非缓存），DB 只存 ID+相对路径+元数据；导入先写 `tmp/` 校验再提交；拍照用 `TakePicture` + FileProvider 完整输出。
- 草稿 500ms 防抖串行写入，`EditorDraft` 以 `new` / `edit:<id>` 为键；提交成功后删除对应草稿。
- 备份为版本化 zip（`manifest.json` + `data.json` + `assets/`原图），SAF 选择位置；覆盖恢复，先校验后在 Room 事务内写入；仅成功导出后更新“最近备份时间”。
- 自励文字在待办页编辑，设置页仅保留显隐开关；内容、显隐、主题与排序存 DataStore，纳入备份。
- 主题：暖白 `#FAF7F2` + 番茄红 `#B94335`，禁用动态取色；深色模式为暖灰配色。
- 平板：内容最大宽度 720dp 居中（手机单列不变）。
- 编辑器：不提供标题输入，列表名称从题目首行生成；历史作业名称保留。顶部云朵是不可点击的草稿状态反馈，每次成功写入后轻微缩放；对勾正式发布。
- 草稿：输入暂停 500ms 后自动保存；返回、切后台和调用相机/相册前提交最新内容。发布前取消并等待旧保存，作业与草稿清理在同一 Room 事务中完成。
- 截止时间：默认不设置；点击时钟按钮打开日期弹窗，可开启具体时间并用表盘/数字输入选择，取消弹窗不修改数据。
- 键盘工具栏：录音、相册、相机、文字格式四个图标；以滑动和淡入显示，格式页提供加粗、背景高亮、字号，选区外格式保留。
- 录音：仅前台申请麦克风权限并录制，停止后插入当前位置；存于 `filesDir/audio/<id>.m4a`，详情与复习页可播放。DB v3 以 `MIGRATION_2_3` 增加录音字段，旧数据无损升级。
- 备份 v4 纳入课程模板、手动排序、课程回收状态以及正式作业、草稿、模板引用的录音；兼容 v1/v2/v3 备份。附件先校验再覆盖，文件和数据库失败时回滚。
- 界面使用暖白方格纸、墨色文字和朱红批注；待办卡片显示手写感摘要、倾斜方框、课程色标及截止信息，自励便签使用朱红边线。深色模式使用暖灰纸面。
- 课程直接分类，所有历史课程统一显示；移除学期管理和学期筛选。内部学期键仅为旧数据/备份兼容保留，选择课程时沿用该课程的内部归属。
- 全部 DAO 写入使用 `@Upsert`，禁用 REPLACE（REPLACE 系先删再插，会触发级联丢数据）。

## 开屏、左滑与附件编辑（2026-09-28）

- 进程首次启动时播放约 1.6 秒的钢笔书写动画，墨线跟随笔尖；可点击跳过，后台返回不重复播放。
- 待办和课程卡片支持向左滑动直接移入回收站；课程连同其已完成和未完成作业一起删除，状态、内容与归属保留。
- 回收站支持整门课程恢复或确认后彻底删除；以前单独删除的作业不随课程批量恢复。
- 课程详情默认显示全部作业，状态与排序使用图标浮窗；复习入口已移除，历史复习数据仍兼容备份。
- 纯图片、纯录音的已发布作业重新编辑时自动补齐输入位置。删除附件时合并两侧文字，回收自动空行并保留富文本与用户换行。
- DB v4 增加 Course.deletedAt，通过 MIGRATION_3_4 无损升级。

### 草稿操作、拖动排序与课程模板

- 草稿：点击卡片继续编辑，向右滑删除。
- 排序：长按卡片后上下拖动；待办、课程、课程内作业各自保存顺序，拖到列表边缘会自动滚动。待办筛选浮窗可切回截止日期/记录时间排序。
- 图片粘贴：复制图片后，在编辑工具栏点击“粘贴图片”图标；原生粘贴菜单、Ctrl+V 和输入法图片提交也接入图片导入。
- 课程详情 → 右上角更多 → 课程模板：支持文字格式、图片、录音，以及每周几和可选时刻。新建空白作业选择课程自动套用；已有内容只更新课程与截止时间。
- DB v5 通过 MIGRATION_4_5 增加可空模板字段，无损保留旧数据。备份 v4 包含模板、附件与手动排序，兼容 v1/v2/v3。
- 本地预览见“构建与安装”；真实手机更新须遵守该节的数据保护步骤。

### 作业截止提醒

- 设置 → 作业提醒可启用或关闭，并在两种统一方式中选择。默认保留原设置：在截止日期前一天的指定时刻提醒，初始为 09:00。
- 选择提前指定时长时，可选 1、6、12 小时或 1、2、3、7 天；有具体截止时刻的作业从该时刻倒推，仅设日期的作业以截止日期当天 09:00 为基准。
- 只提醒未完成、未进回收站、设有截止日期的正式作业，按作业保存的时区计算；超过提醒时刻但尚未到期时可补发。完成、回收、修改期限或关闭提醒会更新安排并移除失效通知。点击通知打开对应作业。
- Android 13+ 需要允许系统通知；Android 12+ 可在设置中授权“准时提醒”，未授权时省电模式可能延迟。重启或应用更新后重新安排；系统强行停止应用后需重新打开。
- 提醒方式、提前时长、开关与指定时刻保存在 DataStore 并纳入 v4 备份；旧备份缺少新字段时沿用前一天指定时刻模式。不修改 Room 表结构或作业、附件数据。
- 在隔离模拟器中打开设置 → 作业提醒；允许系统通知及准时提醒后，可创建测试作业验证。
